# VERDORA

Адаптивный сайт на Vite, HTML, CSS и JavaScript. Локальные шрифты Prata и Lato, фирменный логотип и предметные фотографии.

## Запуск

```sh
npm install
npm run dev
```

## Сборка и форматирование

```sh
npm run format:check
npm run build
npm run preview
```

Production-файлы находятся в `dist/`. Для размещения на статическом хостинге загрузите содержимое этой папки.

## Структура

- `index.html` — структура страницы и нативные диалоги.
- `src/styles/` — базовые стили, дизайн-токены и компоненты по БЭМ.
- `src/scripts/main.js` — адаптивное меню, диалоги и проверка email.
- `src/images/` — используемые фотографии; `-large` для крупных экранов и диалогов, `-small` для карточек, `hero-main.jpg` для первого экрана.
- `src/fonts/` — локальные WOFF2-шрифты и их лицензии.
- `public/` — favicon ICO/SVG, Apple Touch Icon и Open Graph-превью.

Подписка и контакты находятся в отдельной секции `contacts`. Футер содержит только copyright и политику конфиденциальности. Меню и карточки появляются плавно; диалоги закрываются кнопкой, Escape или кликом вне карточки. При `prefers-reduced-motion` анимации отключены.

## Open Graph

Перед публикацией создайте `.env.local` по примеру `.env.example` и задайте реальный публичный адрес в `SITE_URL`, затем повторите сборку. По умолчанию используется localhost, недоступный социальным сетям.

## Ограничения

Это frontend-демонстрация. Оплата, оформление заказа и отправка рассылки не подключены. Email проверяется только в браузере и не сохраняется. `hello@verdora.example` — демонстрационный адрес.

## Лицензии шрифтов

Lato: `src/fonts/Lato-OFL.txt`. Prata: `src/fonts/Prata-OFL.txt`.
